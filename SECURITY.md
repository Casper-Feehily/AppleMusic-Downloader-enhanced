# Security Policy

## Supported Versions

Use the latest [release of the enhanced edition](https://github.com/Casper-Feehily/AppleMusic-Downloader-enhanced/releases).

## Reporting a Vulnerability

Open an [issue](https://github.com/Casper-Feehily/AppleMusic-Downloader-enhanced/issues/new) asking for a private contact method. Keep vulnerability details, credentials, and unredacted logs out of the public issue.
